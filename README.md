# 🚨 OI 爆零警告 🚨

> ⚠️ 谨记竞赛血泪教训，避免低级错误导致爆零！

### 💾 数据相关
- **数据不清空，爆零两行泪。**  
  `memset` 或 `fill` 要到位，多测残留必崩溃！  
  🔥 `memset(head, 0, sizeof(head)); // 图论题尤其注意`

### 📖 输入输出
- **多测不读完，爆零两行泪。**  
  `while(T--)` 必须完整读输入，**EOF 也要判**！  
  ❌ `if(n==0) break; // 题目说"读到0结束"才能用！`

### 🎯 边界特判
- **边界不特判，爆零两行泪。**  
  树题空节点、二分`l=r`、DP的`i=0`都要想！  
  🌰 `if(n==1) { puts("0"); continue; }`

### 🤔 贪心策略
- **贪心不证明，爆零两行泪。**  
  盲目排序一时爽，hack 数据火葬场！  
  📜 **反例**：区间问题按右端点排序不一定最优！

### 🔄 DP顺序
- **DP 顺序错，爆零两行泪。**  
  背包先物后容量，数位DP从高位起！  
  💡 `for(int j=W; j>=w[i]; j--) // 01背包倒序！`

### 🔢 数值细节
- **大小少等号，爆零两行泪。**  
  `<` 还是 `<=`，**样例过了也可能WA**！  
  🌰 `if(l <= r)` vs `if(l < r)`

- **溢出不 long long，爆零两行泪。**  
  十年OI一场空，没开`ll`见祖宗！  
  ✅ `typedef long long ll;`

### � 越界检查
- **越界不判断，爆零两行泪。**  
  数组开`1e6+10`，访问`a[-1]`直接RE！  
  🛡️ `assert(x >= 0 && x < n);`

### 🛠️ 调试技巧
- **调试不注释，爆零两行泪。**  
  `printf("debug:%d\n",x);` 交题前**必须删**！  
  🧹 **宏推荐**：  
  ```cpp
  #define DEBUG(x) cerr << #x << "=" << x << endl
